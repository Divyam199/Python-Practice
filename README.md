* 📄 **day_03.py**
  * Operators
  * Arithmetic Operators: Handles math functions (+, -, *, /, //, %, **).
  * PEMDAS Rule: Dictates operation order (Parentheses, Exponents, MD/AS left-to-right).
  * Assignment Operators: Assigns values using basic (=) or compound (+=, -=) forms.
  * Comparison Operators: Evaluates conditions (==, !=, >, <, >=, <=) returning True/False.
  * Logical Operators: Combines multiple boolean conditions using and, or, and not.
  * Membership Operators: Checks value existence in collections using in and not in.
